Introducción

GIACELIA 1.1 es una plataforma de ingeniería automatizada que permite diseñar, simular y validar sistemas de control eléctrico. Este demo simula el flujo de trabajo basado en planos de AutoCAD Electrical, sin necesidad de instalar software adicional.

Módulos disponibles:

  • Carga de Planos: Simula la lectura de planos eléctricos (.dwg/.dxf) y detecta componentes automáticamente.
  • Migración: Compara versiones de un proyecto y detecta diferencias (añadidos, eliminados, modificados).
  • Ingeniería de Detalle: Genera lista de materiales, cálculos de sección de cable y tabla de cableado.
  • Validación NOM: Valida el diseño contra NOM-001-SEDE-2012 y genera alertas de incumplimiento.
  • Exportación: Descarga reportes en PDF y CSV: BOM, tabla de cableado, diagrama unifilar y reporte de validación.

1. Carga de Planos Eléctricos

  1. Haz clic en Cargar plano de ejemplo para cargar un proyecto de control de motor + tablero precargado.
  2. El sistema renderizará una vista previa simplificada del plano en SVG.
  3. Se mostrará una tabla con los componentes detectados: contacto, relé, térmico, borne, etc.

2. Migración de Proyectos

  1. Carga la versión A (original) y la versión B (nueva) del mismo proyecto.
  2. Presiona Comparar versiones.
  3. Se mostrará un reporte de diferencias con estado de cada componente.

3. Ingeniería de Detalle

  1. Ingresa la potencia del motor (HP), voltaje y número de fases.
  2. Presiona Generar ingeniería de detalle.
  3. Se generará automáticamente:
    • Lista de materiales (BOM) con cantidades y referencias.
    • Cálculo de sección de cable y protecciones (disyuntor, térmico).
    • Tabla de cableado (origen → destino, borne, sección).

4. Validación Normativa

  1. Presiona Ejecutar validación (requiere haber cargado un plano).
  2. El sistema evalúa el diseño contra NOM-001-SEDE-2012.
  3. Se mostrarán alertas de incumplimiento con ubicación aproximada en el plano.

5. Exportación de Reportes

  1. Selecciona el tipo de reporte que deseas descargar:
    • Lista de Materiales (BOM): CSV con todos los componentes y cantidades.
    • Tabla de Cableado: CSV con conexiones origen-destino y sección de cable.
    • Reporte de Validación (PDF): Informe de cumplimiento normativo con alertas.
    • Diagrama Unifilar (PDF): Esquema simplificado del sistema eléctrico.
