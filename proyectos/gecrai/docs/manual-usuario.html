Manual de Usuario - GECRAI 1.1

Generador de Consultas Regulatorias con Asistencia Inteligente

1. Introducción

GECRAI 1.1 es una plataforma diseñada para automatizar consultas regulatorias, generación de memorias de cálculo y validaciones normativas en entornos industriales.

2. Arquitectura

  • Frontend: interfaces responsivas orientadas a usuario industrial
  • Backend: lógica de negocio y validaciones normativas
  • Base de datos: almacenamiento de normativas y memorias
  • IA: motor de consulta y generación de documentos

3. Requisitos

  • Navegador moderno
  • Conexión a internet para servicios en la nube
  • Permisos de administrador para instalación local

4. Instalación

Descargá el instalador correspondiente a tu sistema operativo y ejecutá el asistente de instalación.

Pasos básicos:

  • Descargar el paquete de instalación
  • Ejecutar el instalador
  • Configurar credenciales iniciales
  • Verificar conexión con el servicio de normativas

5. Funcionalidades principales

5.1 Consulta de normativas

Buscá normativas por clave, sector o alcance. El sistema sugiere documentos relacionados y versiones vigentes.

5.2 Generación de memorias

Generá memorias de cálculo automáticas a partir de parámetros de entrada como voltaje, corriente y tipo de instalación.

5.3 Validaciones

  • Validación NOM-001-SEDE-2012
  • Cálculo de Arc Flash IEEE 1584
  • Integración con AutoCAD / Revit

6. Uso de la demo

La demo incluye:

  • Simulación de inicio de sesión
  • Dashboard con métricas
  • Formulario de consulta regulatoria
  • Resultado de memoria de cálculo
  • Historial local de consultas
